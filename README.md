## 📋 Descripción

Ruta de aprendizaje estructurada para dominar **DevOps desde cero hasta un nivel avanzado**. Diseñada especialmente para desarrolladores que buscan ampliar sus competencias hacia la cultura DevOps, la automatización de infraestructura y el ciclo de vida completo del software.

Combina teoría, práctica y recursos multimedia para un aprendizaje efectivo.

## 🎯 Objetivos de la Ruta

1. **Dominar la terminal y scripting** (Bash, PowerShell, Shell)
2. **Comprender la cultura DevOps** — CI/CD, IaC, monitoreo y colaboración
3. **Gestionar infraestructura como código** con Ansible, Puppet y Chef
4. **Desplegar en la nube** con automatización y contenedores
5. **Implementar pipelines de CI/CD** completos y eficientes

## 📚 Estructura de la Ruta

### Fase 0: Dominio de la Terminal
*Base esencial antes de entrar al mundo DevOps*

- Fundamentos de la Shell (navegación, permisos, redirección)
- Herramientas CLI (grep, find, awk, sed, tar)
- Scripting básico en Bash y PowerShell
- Editores en terminal (Vim/Nano)

### Fase 1: Fundamentos de DevOps
*Filosofía, principios y primeros pasos*

- Cultura DevOps y metodologías ágiles
- Control de versiones con Git avanzado
- Introducción a CI/CD
- Principios de la nube (AWS, Azure, GCP)

### Fase 2: Contenedores y Virtualización
*Docker, Kubernetes y orquestación*

- Docker desde cero
- Docker Compose para entornos multi-servicio
- Kubernetes: pods, servicios y deployments
- Registros privados de imágenes

### Fase 3: Infraestructura como Código (IaC)
*Automatización de infraestructura*

- Terraform para aprovisionamiento cloud
- Ansible para gestión de configuración
- Puppet vs Chef: cuándo usar cada uno
- Gestión de secretos y configuración

### Fase 4: Observabilidad y Seguridad
*Monitoreo, alertas y buenas prácticas*

- Logging centralizado (ELK Stack)
- Monitoreo con Prometheus y Grafana
- DevSecOps: seguridad integrada en el pipeline
- SRE: Site Reliability Engineering básico

## 🚀 Cómo Iniciar

1. **Lee el [roadmap completo](roadmap.md)** para planificar tu ruta
2. **Comienza con la Fase 0** — dominar la terminal es fundamental
3. **Sigue el orden de las fases** — cada una construye sobre la anterior
4. **Practica con proyectos reales** en cada fase
5. **Obtén tu certificado** al completar la ruta
